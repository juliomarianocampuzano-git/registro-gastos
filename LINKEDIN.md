Publique un proyecto chico de Gastos del mes, pensado para practicar python, html, javascript, sqlite con un alcance junior. Que hace: App en Python, HTML/JS y SQLite para registrar gastos del hogar por categoria, ver totales del mes y detectar en que se va la plata. Automatiza el control de plata diaria/mensual sin planillas complicadas. Como lo arme: deje un entry point claro, datos de ejemplo y tests cortos. El codigo esta simple a proposito, para que se pueda revisar sin un tour guiado. Limite honesto: no escala a produccion, no cubre todos los casos ni tiene autenticacion; es un ejercicio para mostrar criterio, no magia. Lo arme para Repo: https://github.com/juliomarianocampuzano-git/gastos-del-mes Que le cambiarias primero: tests, README o el modelo de datos? #python #sql #automatizacion
